# Inicio rápido — Grupo 16

Instala Node.js 20+ y abre una terminal en esta carpeta.

```
npm run dev
```

Abre http://localhost:5173. Pulsa «Cargar datos DEMO». Explora «Datos maestros», «Registros operativos» y «Consulta y trazabilidad». En esta copia los datos se almacenan solo en este navegador.

```
npm test
npm run build
```

Si deseas conservar datos, usa «Exportar respaldo JSON». Para restablecer DEMO pulsa el mismo botón, que solicitará confirmación antes de sobrescribir los registros locales.
